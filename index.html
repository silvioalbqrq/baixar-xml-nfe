RODA SOMENTE LOCAL — esta página no GitHub é só demonstração.

Para usar de verdade, no Windows: baixe o repositório, instale Python 3.12+ + Google Chrome e dê duplo-clique em iniciar_xml.bat (abre http://127.0.0.1:8002/). O BUSCAR / lote / download só funcionam com o backend local ligado. Regras completas no README do repositório.

Você abriu o arquivo direto (sem backend).

O navegador bloqueia que um .html execute o .bat, então faça assim:

  1. Feche esta aba e dê duplo-clique em Abrir Site Local (atalho) ou em iniciar_xml.bat — ele liga o backend e abre o navegador padrão sozinho.
  2. Se o backend já estiver ligado, clique aqui para abrir o site local.

Aguardando o backend iniciar… se você já rodou o .bat, aguarde aqui que esta aba vai sozinha para o site.
